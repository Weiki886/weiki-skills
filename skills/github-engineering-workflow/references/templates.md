# 检查表与模板

## Definition of Ready

- [ ] Proposal/ADR 已接受，目标、非目标与用户价值明确。
- [ ] Issue 已归属 Milestone，Owner、依赖与阻塞可见。
- [ ] 风险级别与依据已记录；高风险已安排领域 Owner 与威胁/风险评审。
- [ ] 验收标准可观察、可重复验证。
- [ ] 接口、数据、兼容性与迁移影响已说明。
- [ ] 测试、文档、可观测性、发布与回滚/前滚已按风险规划。
- [ ] 未决问题不会根本改变实现方向。

## Definition of Done

- [ ] PR 已关联 Issue，人工 Review、阻塞意见与必需 CI 已闭环。
- [ ] 主干构建、测试与适用安全检查通过，无未登记 flaky gate。
- [ ] 文档、ADR、运行手册、迁移与 Feature Flag 生命周期已同步或不适用。
- [ ] 权威构建产物可追溯到源 Commit；摘要及按风险所需 SBOM/来源证明已保存。
- [ ] 目标环境验证完成，用户健康信号正常，回滚/前滚路径可执行。
- [ ] Release Notes、Issue、Milestone、遗留风险与后续任务已更新。

- 备选方案：
- 选择理由：
- 放弃理由：

## 本轮范围
- 做：
- 不做：
- 边界与约束：

## 设计
<先写文字；文字确认后再附原型或 Demo>

## 验收标准
- [ ] <可观察、可重复验证的结果>

## Review 检查表

- [ ] PR 与 Issue、Proposal、Milestone 一致。
- [ ] 改动小而聚焦，无无关重构或格式化噪音。
- [ ] 风险级别合理，门禁与爆炸半径匹配。
- [ ] 方案方向、模块边界、接口和数据模型合理。
- [ ] 作者能解释关键逻辑和 AI 生成内容。
- [ ] 核心路径、边界条件和回归风险有测试。
- [ ] 必需 CI、构建和安全检查通过。
- [ ] 构建产物可追溯且在后续环境中未重新构建。
- [ ] 文档、变更记录、兼容性、部署、健康信号和恢复信息完整。
- [ ] Feature Flag、临时例外和隔离测试都有 Owner 与到期日。
- [ ] 阻塞意见已解决，关键结论已留痕。

## 审计证据矩阵

逐项给出 `PASS`、`FAIL` 或 `UNKNOWN`，并附具体 URL、编号、Commit、Tag、文件路径或命令输出。

| 检查项 | 最低证据 |
| --- | --- |
| 设计先行 | 已接受 Proposal，含取舍、非目标和验收标准 |
| 架构成立 | 边界、接口、数据模型、风险和可串联主干 |
| Milestone 管理 | 目标、截止时间、全部关联 Issue 和可见进度 |
| Issue 可执行 | 背景、目标、非目标、验收、依赖和规格 |
| PR 可追溯 | PR 关联 Issue，范围一致，验证证据完整 |
| Review 有效 | 人工批准、阻塞意见闭环、自动检查结果 |
| 主干可用 | 合并后构建和核心测试通过 |
| 风险裁剪 | Issue/PR 风险依据明确，高风险门禁与例外可审计 |
| CI 反馈 | 每次改动触发可靠快速层，慢层有处置责任，flaky test 有期限 |
| 构建可信 | 权威不可变产物绑定源 Commit、构建运行和摘要 |
| Actions 安全 | 最小权限、外部 Action 固定 SHA、工作流 Owner、无特权执行不可信代码 |
| 依赖与凭据 | 依赖图/锁文件/审查、凭据扫描与泄漏轮换证据 |
| 供应链 | 发布制品按风险提供 SBOM、来源证明/签名及部署前验证 |
| 部署安全 | 同一产物晋级、环境保护、smoke test、渐进式发布和恢复路径 |
| 兼容性 | API/Schema 使用兼容迁移，破坏性变化有消费者与恢复计划 |
| 可观测性 | 上线前定义用户健康信号、停止条件和负责人 |
| 紧急路径 | 绕过有授权、范围、时限、补偿控制和恢复后闭环 |
| 文档演进 | 变更为追加记录，用户与工程文档同步 |
| Release 完整 | Tag、Release Notes、交付列表、已知问题和试用方式 |
| AI 责任在人 | 关键 Prompt 摘要、人工复核、作者可解释代码 |
| 信息安全 | 仓库可见性匹配内容，无凭据或受限信息泄漏 |
| 仓库治理 | 默认分支保护、审批规则、必需 CI、模板和责任边界 |
| 效能改进 | DORA 五指标按单服务看趋势，口径稳定并用于改进瓶颈 |
| 指标诚信 | 无操纵 Star、Review、投票、部署、失败或其他指标的证据 |

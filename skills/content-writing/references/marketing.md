# 营销文章细则

把「为什么选我 / 你能得到什么 / 现在行动」讲清楚，并促成一次行动。价值来自共鸣与可信。

## 结构骨架

从 PAS 与 AIDA 中选一个，不混用：

- **PAS**：Problem（问题）→ Agitate（放大痛点）→ Solution（解决方案）。
- **AIDA**：Attention（注意）→ Interest（兴趣）→ Desire（欲望）→ Action（行动）。

## 各环节要点

1. **钩子 / 注意**：用具体场景、数字、反差或提问开头，不用「在当今…的时代」。
2. **痛点 / 兴趣**：只写你真实服务的群体痛点，用他们自己的语言，切勿泛化为「所有人」。
3. **解决方案 / 欲望**：说清「怎么解决」和「为什么选你」，用可验证的证据。
4. **可信度**：真实案例、客户名、数据、截图、第三方评价；没有就补，不虚构。
5. **消除风险**：明确不适用的人、退换 / 试用 / 问询门槛，降低行动阻力。
6. **CTA**：一篇文章只推一个主动作；CTA 一句话、一个方向。

## 反空话红线

- 没有具体数字 / 案例 / 证言，就不允许写「提升效率」「行业领先」「赋能」「助力」等说法。
- 避免只有形容词没有事实的段落；每个卖点都配一个「所以你能得到什么」或一个证据。
- 统计数字必须注明口径与来源；比例、百分比要写清基数。

## 语气与长度

- 有感染力但不说教；面向目标读者，用短句、短段落保证手机端可扫读。
- 营销文案不以长度论质量；能用三句讲清就不用三段。
- 结尾 CTA 前置时，正文仍要给足「为什么现在、为什么值得」的理由。

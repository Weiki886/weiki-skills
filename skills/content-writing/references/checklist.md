# 事实核查、校对与反 AI 味清单

写完全文后逐条过；标记未核实的点，不要假装已核实。

## 事实核查

- [ ] 数字、百分比、时间、版本号有来源且口径一致。
- [ ] 代码与命令真实可运行（technical）；案例 / 客户 / 数据真实（marketing）。
- [ ] 链接可访问、指向正确；人名、产品名、专有名词拼写正确。
- [ ] 无「显然」「众所周知」等跳过论证的占位。
- [ ] 未来源 / 不确定的内容已标注或删除，未虚构任何内容。

## 反 AI 味

- [ ] 无「值得注意的是」「总而言之」「赋能」「助力」「随着…的不断发展」等套话。
- [ ] 无三段式平均结构、无观点先行却无细节的空泛段落。
- [ ] 有具体细节与「只有真正写过 / 用过的人才知道」的信息密度。
- [ ] 每段只讲一件事；删掉重复与车轱辘话。
- [ ] 开头不是背景铺垫堆砌，而是直给结论、场景或问题。

## 校对

- [ ] 只保留一个主线；偏题段落删除或移走。
- [ ] 术语首次出现有解释，前后用词统一。
- [ ] 标题与正文一致，没有文不对题。
- [ ] 段落删除后仍连贯；冗余句子删到「再删一句就丢信息」为止。
- [ ] 目标平台格式正确（Markdown 渲染、富文本、首图比例、摘要字数）。

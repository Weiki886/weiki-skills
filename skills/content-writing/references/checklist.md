# 人机分工、事实核查与交付质检

先划清人机边界，再分层质检。宁可标「待核实」，不假装已核实，也不虚构。

## 写前：人机分工（先划边界）

这些最容易被 AI 写假，必须由作者提供，缺失就停下问，不硬写：

- **一手观察与真实经历**：真正做过的事、踩过的坑、真实运行过的代码 / 结果。AI 不得用「比如有一次…」编造场景。
- **核心角度与判断**：让整篇立住的创意和立场。AI 可以给候选，最终拍板必须是作者。
- **真实情绪与体感**：写「我当时愣了半天」，不写「我深感震撼」。
- **数据到具体的人**：从「1000 个已付款」想到背后那个活人，这种温度得作者真有体会才有。

放心交给 AI 的：

- 找论据、类比、比喻；按既定角度扩写；补背景知识；梳理逻辑与结构建议。

原则：素材不足就先补素材，别用技巧掩盖。

## 事实核查

- [ ] 数字、百分比、时间、版本号有来源且口径一致。
- [ ] 代码与命令真实可运行（technical）；案例 / 客户 / 数据真实（marketing）。
- [ ] 链接可访问、指向正确；人名、产品名、专有名词拼写正确。
- [ ] 无「显然」「众所周知」等跳过论证的占位。
- [ ] 未来源 / 不确定的内容已标 `[待核实]` 或删除，未虚构任何内容。
- [ ] 引用已标版本与日期；实验 / 数据说明了口径与局限。

## 反 AI 味：先删信号

高频信号出现即改，宁可更直白：

| 类别 | 典型信号 | 改法 |
|---|---|---|
| 空话前缀 | 值得注意的是、总而言之、众所周知、随着…的不断发展 | 删掉，保留后面的事实 |
| 高频雷词 | 说白了、本质上、换句话说、意味着、不可否认、综上所述、首先…其次…最后 | 换口语或直接删 |
| 拔高词 | 赋能、助力、打造、引领、重塑、里程碑、关键作用、重要体现 | 换成具体做了什么 |
| 连接词堆砌 | 此外、与此同时、进一步地、不仅…更是… | 该删就删，用事实的自然顺序连接 |
| 三段式排比 | 无缝、直观、强大的三连形容词；三个整齐短句 / 小标题 | 拆成两句，或改成两项 / 四项 |
| 对仗与金句化 | 「官方文档教你命令，不教你干活」这类工整对句 | 打散成不平整的口语 |
| 非 A 即 B | 不是「X」，而是「Y」 | 直接说 Y |
| 拔高象征 | 标志着、见证了、是…的证明、象征着 | 回到事实本身 |
| 结尾总结块 | 文末「总而言之」式复述段落 | 让末句自然收尾，不复述全文 |
| 过度铺垫 | 开头大段背景 / 价值宣言，迟迟不进正题 | 开头直给结论、场景或问题 |
| 假设性例子 | 「比如有一次…」编造场景 | 换成「我今天正在用的 X」这种真实细节，或删掉 |
| 加粗满屏 | 每段开头一个加粗标签，像 PPT 要点 | 最多保留 1–2 处强调，其余融入行文 |

能说「帮用户省时间」就不说「提升用户效率」。

## 反 AI 味：注入「人味」

删掉信号只是及格，还要有人的声音：

- [ ] **有观点**：对事实做出反应，而不是中立复述；允许说「我更倾向」「踩坑后发现」。
- [ ] **节奏有变化**：短句与长句交错；两三个短句之后接一个展开的长句。
- [ ] **信任读者**：不逐字解释隐喻，不过度限定，不把读者当小白手把手。
- [ ] **承认复杂**：写出代价、不确定性、不适用场景，比「无懈可击」更可信。
- [ ] **具体到感受与细节**：不是「结果令人担忧」，而是「凌晨三点没人盯着时，它还在不断写代码」。
- [ ] **允许一点不完美**：适度的口语、第一人称、题外话，好过塑料般的规整。

## 可扫读

- [ ] 一段只讲一件事；段落短到手机屏上一眼到底（约 ≤4 行）。
- [ ] 小标题能独立串起全文要点，只看标题也能知道说了什么。
- [ ] 列表 / 代码块 / 表格 / 图与正文互相印证，不出现「如下」却无下文。
- [ ] 关键结论有真实结果或例证，而不是只有形容词。

## 校对

- [ ] 只保留一个主线；偏题段落删除或移走。
- [ ] 术语首次出现有解释，前后用词统一。
- [ ] 标题与正文一致，没有文不对题。
- [ ] 段落删除后仍连贯；冗余句子删到「再删一句就丢信息」为止。
- [ ] 目标平台格式正确（Markdown 渲染、富文本、首图比例、摘要字数）。

## 交付前终审：活人感

只回答一个问题：**「读完像是一个真实的人，认真在跟你讲一件他在乎的事；还是 AI 在输出信息？」**

按 4 条过：

- [ ] **温度感**：情绪是体感记忆（「我当时就愣住了」），不是知识性描述（「这令人震撼」）。
- [ ] **独特性**：有没有「只有这个作者才会写的角度」；换个 AI 也能写出来就不算过。
- [ ] **姿态**：像有见识的普通人在聊天，还是滑进了导师教学 / 品牌宣发的口气。
- [ ] **心流**：从头读到尾，有没有某处注意力断掉、要返回重读？断点就是需要修的节奏问题。

任何一条让你觉得「这段 AI 味重」，就返工那段，用更口语、更私人、更不完美的方式重写。

## 可选：交付质检报告

对全文跑一遍，输出简短结论：

```
- 事实核查：✅ / ❌（列出待修点）
- 反 AI 味：✅ / ❌（命中词 X 处）
- 活人感：✅ / ❌（具体哪一段）
- 下一步：优先修 1–3 个问题
```
